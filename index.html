実装時に意識したこと

  • バリデーションエラーメッセージは、ユーザーが入力内容のどこに問題があるかを理解しやすくするためのものだと考え、その目的を意識しながら実装しました。

  • メール認証の要件は、認証済みユーザーのみが利用できる安全性を確保するためであることを意識しながら実装しました。
  • PHPUnitを使用し、各機能が要件どおりに動作することを確認しながらテストを実施しました。

WORK 02

勤怠管理アプリ

勤怠管理・修正申請・承認機能などを備えたWebアプリケーションです。

GIF・スクリーンショット

使用技術

  • PHP
  • Laravel
  • MySQL
  • Docker
  • Fortify
  • Sanctum
  • Vite
  • SCSS
  • PHPUnit

実装時に意識したこと

  • 勤務状況に応じて表示するボタンを切り替える要件について、一般スタッフの誤操作を防ぐためであることを意識しながら実装しました。
  • 修正申請中の勤怠は再編集できない要件について、申請内容が承認されるまで変更を防ぎ、データの整合性を保つためであることを意識して実装しました。
  • 申請一覧画面で管理者と一般スタッフが同じパスを使用する要件について、認証ミドルウェアで利用者ごとに適切な画面へ遷移させる目的を理解しながら実装しました。
  • PHPUnitを使用し、各機能が要件どおりに動作することを確認しながらテストを実施しました。
